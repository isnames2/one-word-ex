## The entry

`main.py` (pure Python standard library, no other imports) writes exactly
one word to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

**Forgettable**

The word an ex would use to describe the entrant. Not an insult hurled in
anger, but the quiet verdict reached months later — the realisation that
you left no mark at all. It stings precisely because it is calm, plausible,
and impossible to argue with: you cannot prove you were memorable.
Funny, painful, and instantly relatable — the kind of word people repeat
because they have lived it too.

## Run

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
cat output/entry.txt
```
